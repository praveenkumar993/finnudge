# FinNudge � Real-Time Financial Personalization Engine

Behavioral personalization engine that learns individual user financial
patterns and serves hyper-relevant product nudges in real time.

## Architecture
- Two-tower neural retrieval model (PyTorch)
- Online learning with River (real-time embedding updates)
- A/B testing framework with statistical significance
- FAISS vector search for sub-50ms recommendations
